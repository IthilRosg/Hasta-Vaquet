## Что не заработало

- **yamux over WS** — нужен серверный yamux, на сервере нет. Требует доработки.
- **XHTTP** — нужен серверный HTTP chunk handler. В текущей архитектуре WS — ближайший аналог.

## Рекомендации по мутациям

**Chimera Final** (лучшее из всех):
```
База: UDP (880 Mbps, 46ms)
  ├── Маскировка: QUIC-header (7 байт префикс) + Large Padding (0-200)
  ├── Надёжность: adaptive FEC=2 при >5% потерь
  ├── Fallback: WS при блокировке UDP
  └── Параллельность: 4 UDP сокета (если нужно >1 потока)
```

Ожидаемая скорость Chimera Final: **~800 Mbps** с маскировкой.

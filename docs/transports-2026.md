# Актуальные транспорты на май 2026

## Что уже есть в Hasta-Vaquet

| Транспорт | Статус | Скорость | DPI |
|---|---|---|---|
| Raw UDP | ✅ | 810 Mbps | ❌ |
| UDP + Large Padding | ✅ | 784 Mbps | ⚠️ |

| WebSocket (WS) | ✅ | 189 Mbps | ⚠️ |
| WSS (Cloudflare) | ❌ | — | Cloudflare лимиты |

## Что можно добавить

### 1. Mux (Multiplexing) над WS
Обёртка над WebSocket, которая мультиплексирует несколько логических потоков через одно TCP-соединение. Каждое приложение (браузер, мессенджер, игра) получает свой поток внутри одного WS. Без Mux все приложения делят один поток — пакеты могут блокировать друг друга (HOL blocking).

**Реализация:** github.com/hashicorp/yamux / github.com/xtaci/smux — берут `io.ReadWriteCloser` (наш WS) и создают N виртуальных стримов.

**Скорость:** ожидается ~200 Mbps (overhead только на заголовки стримов, ~12 байт)

### 2. SplitHTTP / XHTTP-like
Данные режутся на HTTP-чанки и отправляются как POST-запросы. Каждый чанк — отдельный HTTP-запрос с разными URL. DPI видит обычный HTTP-трафик, не может определить что это VPN.

**Реализация:** клиент шлёт POST /api/chunk/XXXX с телом = фрагмент данных. Сервер отвечает 200 OK. Фрагменты случайного размера (1-64KB) со случайными интервалами.

**Скорость:** ~150 Mbps (overhead HTTP-заголовков)

### 3. gRPC (HTTP/2)
Использует HTTP/2 streaming через gRPC. Трафик выглядит как gRPC-вызовы. Поддерживается Xray/V2Ray.

**Реализация:** protobuf + gRPC Go библиотека. Тяжелая зависимость.

**Скорость:** ~180 Mbps

### 4. MASQUE (RFC 9484)
IETF-стандарт для прокси IP-пакетов через HTTP/3 (QUIC). Неотличим от обычного QUIC-трафика.

**Реализация:** требует quic-go. Поддерживается sing-box.

**Скорость:** ~300 Mbps

### 5. Mux + Reality
Комбинация: Reality маскирует TLS, Mux над WS внутри Reality. Reality скрывает факт использования VPN, Mux оптимизирует многопоточность.

**Скорость:** ~250 Mbps (TLS + WS + Mux overhead)

## Вывод

Самое практичное для нас сейчас: **Mux над WS** — минимальные изменения кода, максимальный прирост в многопоточности. SplitHTTP — перспективно для DPI- evasion, но требует больше реализации.
